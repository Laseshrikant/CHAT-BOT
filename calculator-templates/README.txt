Calculator (Web) Project

How to use in a website:
1) Open this file in your browser:
   calculator-templates/index.html
2) It works as a normal website page (no installation).

If you want to serve it via a local web server:
- Create a simple server in any editor, or use VS Code Live Server extension.
- Point it to calculator-templates/index.html

Files:
- index.html
- styles.css
- app.js
